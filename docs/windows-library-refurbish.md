# Windows 图库翻新

## 启动时自动翻新

升级后的 Windows 程序首次打开有图片的旧图库时，会先显示原图库，再在后台静默翻新。期间可以浏览、搜索和滚动，改库操作等翻新完成后恢复。静态图按普通导入的规则清洗；动图、不支持清洗的文件和重复条目都不会被删除。原图片与原索引保存在该图库的 `maintenance-backups/refurbish-v1-*/original` 下，收件箱、缓存、外观等数据留在原位置。

成功切换后，图库目录会写入版本标记 `.windows-library-refurbish-v1`；以后打开只检查标记，不再为翻新扫描图片。空间不足以暂存图库副本时，本次启动保留旧图库；途中中断会先恢复旧版本。未成功的图库可在下次启动重试。新建空库和新版独立工具生成的副本也有标记，不需要再跑一遍。

已在局域网同步历史中的图片，如果清洗会改变内容标识，保留原图，避免另一端仍用旧版时把它识别为删除和新增。普通导入优先比对清洗后的图片；图库仍保留原尺寸时，也会对原始内容做精确比对。

## 手动制作副本

翻新工具把旧 `data` 目录重建为一个新的图库目录。普通图片导入和翻新共用同一个缩放规则：静态图长边最多 720 像素，等比例缩小，不裁切、不放大。静态图重新清洗成 PNG；多帧 GIF、APNG 等动画保持原样。无法清洗的文件也保留，不自动删除重复图片。

先从托盘退出 SuzuEmojy，并停止其他正在写入源图库的程序。使用 PowerShell 在仓库根目录执行：

```powershell
dotnet build win_refurbisher/SuzuEmojy.LibraryRefurbisher.csproj -c Release -p:UseSystemWindowsRuntime=true -o dist/refurbisher
.\dist\refurbisher\SuzuEmojy.LibraryRefurbisher.exe .\data .\dist\refurbished-library
```

第二个路径必须是尚不存在的目录，其父目录必须已存在。工具不覆盖或切换原图库。索引完成后才把临时目录改名为输出目录；如中途取消或失败，原图库仍可照常使用。要识别和清洗静态 WebP，可将便携包 `bin` 目录中的 `suzu-webp.dll` 放在翻新工具旁。

新目录保留分类、分类图标、关键词、排序、最近使用和外观设置。清洗后的文件重算内容索引；普通导入使用同一套缩放规则，哈希只用于找候选，静态图还要核对输出尺寸和每个像素，动图则核对文件字节。不同原图如果在缩小后变得完全相同，普通导入会视为同一张成品；翻新只报告这类重复，不删除或合并旧条目。资源包和局域网同步仍使用各自协议原有的内容身份。

缓存、收件箱和旧备份不迁入新库；收件箱和备份仍留在源库。输出内的 `refurbish-report.json` 列出改名、未清洗文件和精确重复组。可用 Windows 程序的 `--data <新目录绝对路径>` 打开副本检查。
