# Windows 原生前端预览

这是 Windows 2.0 的独立 WPF 预览入口，不替换现有的 Qt 版。`main.py` 和现有发布流程保持原样。SQLite 和 JSON 沿用原格式。WPF 按需启动短命的 Python 子进程来读写图库，不加载 Qt，也不启动常驻 Python 服务。原有配色表由两套前端共用。

## 试用

需要 .NET 8 Desktop Runtime、Python、Pillow 和可用的 Python 源码目录。TG 下载需要 `requests`；WebM 和 TGS 转换也需要对应的旧版转换依赖。在仓库根目录运行：

```powershell
dotnet build win_frontend/SuzuEmojy.Windows.csproj -c Release -o dist/win-frontend-category-submenu-preview
.\dist\win-frontend-category-submenu-preview\SuzuEmojy.Windows.exe
```

默认使用仓库的 `data` 目录。第一次试用建议传 `--data <图库副本目录>`。如果 Python 不在 PATH，可以给试用进程设置 `SUZU_PYTHON` 指定 Python 路径。**本版支持写入和删除，请勿让 Qt 与 WPF 同时写同一图库。** 单帧 GIF 缓存在对应数据目录的 `cache/gif_output`。

已迁：

- 图库浏览、分类切换、搜索、Fluent 筛选、悬停静态图和 GIF、拖出文件。支持拖入文件或目录，以及从剪贴板导入文件或位图。
- 分类新建、重命名、排序、删除、自定义图标；单张和批量分类、关键词、删除和文件导出；表情拖动排序。
- 资源包导入、完整或按分类导出、分卷，沿用 `资源包-part1.zip` 命名。感知哈希扫描显示候选，由用户勾选后才删除。
- 常用设置（外观、主题色、置顶、面板尺寸、预览、热键和发送格式）、Windows 托盘、主面板、快速面板。

设置从主面板或托盘打开，在主窗口里单独占一页。修改自动保存；点击返回或按 Esc 回到图库，保留原来的浏览位置。

在「设置 → 个性化 → 背景图片」为主窗口和快捷窗口选择同一张背景。两者共用解码后的图片，分别按窗口比例居中裁切并铺满，快捷窗口保留边框和圆角。只有使用背景图时才显示模糊度、亮度和遮罩不透明度，调节时在主窗口实时预览，保存后也应用到快捷窗口。亮度负值调暗、正值调亮，0 保持原样。遮罩跟随主题底色，均匀覆盖整个窗口；默认 20%，调到 0% 即关闭遮罩。软件只读取数据目录 `appearance/window-background` 中优化过的副本。更换时先写好新图，再原子替换旧副本；失败则保留旧背景。清除背景只移除这份副本，原图始终不受影响。

感知哈希去重也在主窗口里单独占一页。手动开始扫描，可取消；调整阈值后复用已缓存的特征重新匹配。结果按组分页，点图进入页内大图，用方向键跨组浏览，用 Del 切换删除勾选。返回箭头和 Esc 优先回到结果列表或收起删除确认。确认删除之前不会移除文件；删除完成后同步刷新图库和结果。

双击「全部表情」切换分类列表和图标网格，两种模式都以中性细描边标出当前分类。在图标网格或右侧主图库内按 Ctrl＋滚轮缩放，各自记住尺寸；普通滚轮仍用来滚动。两个网格均从左上角起排，优先放下尽可能多的完整列，再均分余量；不足一行的项目沿用相同列位置。列表和图标网格分别记住侧栏宽度。

右键已有分类选择「批量选择」，会切到该分类并进入选择模式；不会自动选中图片。「全选」只作用于当前视图内的结果，批量删除仍需确认。

右键单张或批量选中的表情，「添加到分类」「移动到分类」会展开二级菜单，点击目标直接执行。移动仅在当前分类内提供，移出该分类但保留其他归属。二级菜单、导出指定分类、QQ 导入目标和感知哈希扫描范围使用侧栏同款收藏夹图标。下拉收起后保留当前图标，收藏夹右键菜单顶部显示该收藏夹的图标和名称。

主图库和左侧分类图标网格共用缩放重排动画，优先保持指针下的条目在视口中的纵向位置。连续缩放从当前画面接续，保留按钮和已解码的图标。切分类时，共有的表情移到新位置，当前可见但不属于目标分类的表情短暂淡出。关闭 Windows 动画效果后直接换位，仍复用缩略图。

右侧图库可按住鼠标中键拖动，也可单击中键进入自动滚动，移动鼠标控制方向与速度。再点击、使用滚轮、按 Esc 或切出窗口即停止。滚动期间不弹出悬停预览。

单张图片成功导入后刷新图库，并在右上角短暂显示「导入完成」，不弹窗。普通批量导入显示实际处理张数和进度，完成后用同一类提示反馈。文件夹导入先显示扫描状态，确认总数后显示真实进度；完成时弹出旧版字段的汇总，包括扫描总数、图片数、成功、重复、失败、忽略和子目录数量。扫描或解析问题在同一个汇总窗口里列出。

在主图库按 Ctrl+V，优先导入剪贴板里的本地文件，其次从浏览器复制内容的 `<img src>` 或纯文本 HTTP(S) 直链下载，最后才用剪贴板里的静态位图。也可把浏览器图片/图片直链直接拖到主图库；优先使用浏览器提供的原图地址。网络图片沿用相同的清洗、查重和分类逻辑，APNG 直链会按原始多帧转换成 GIF，不会先拍平成截图。粘贴到搜索框时仍按纯文本编辑处理。

导入进行时，可继续拖入或粘贴图片，后续任务按输入顺序等待，并记住提交时的分类。批量文件、文件夹和链接下载的进度卡可取消当前任务；已经入库的图片保留，后续队列继续，源文件不删除。若当前文件正在清洗或写库，会先等它安全结束。单张本地图片沿用不弹窗的行为，ZIP 资源包写入不支持中途取消。

将文件另存到当前图库下的 `inbox`（默认 `data/inbox`）可自动入库，主窗口收起时也会检查。新文件会等大小和最后修改时间稳定且没有写入占用后才处理。`.apng` 和包含 APNG 动画的 `.png` 都支持，WebM／TGS 仍需对应的转换工具。成功或判重后消耗收件箱里的源文件；失败件移到 `inbox/failed`，2.0 不按旧版的 7 天规则自动删除，可手动移回收件箱重试。自动导入不套用当前画面上的分类，也不抢焦点或重置滚动。

「导入导出」是独立页面，支持导入图片、文件夹和资源包、完整或按分类导出、资源包分卷。资源包沿用旧版 ZIP v1（`manifest.json`、`catalog.json` 和资源文件）；前端只增加了进度订阅，没有改协议。

「第三方导入」下有两个独立子页。「扫描 QQ 聊天表情」可自动检测或手动选择 `Tencent Files` 目录，再选择账号和缓存分类、预览并导入所选或全部。扫描显示已遍历的文件夹和候选文件数，候选清单确定后显示实际检查进度。扫描和导入不改动 QQ 缓存；如需清理，用「删除所选缓存…」确认后将选定的 QQ 原文件移到 Windows 回收站。文件已变化、无法验证或不能安全移到回收站时保留文件；不删除图库副本，也不清理未选中的缩略图或其他文件。「下载 TG 贴纸」接受 `addstickers`、`addemoji` 链接或包名，可选择自动、原始、PNG 或 GIF 下载到文件夹，或直接清洗入库到 `TG_<包名>`。下载附带的可选 ZIP 是普通压缩包，不是图库资源包。TG 需要自己提供 Bot Token，仅当前页使用；默认直连官方 HTTPS API，不回落到旧版内置反代，只有显式填写 HTTPS 反代时才向它发送 Token。

QQ 和 TG 的结果按原图比例排成连续滚动的瀑布流。点击图片可以选中并在右侧查看大图，窄窗口中大图放在列表上方。勾选框和 Ctrl 支持多选，Shift 可选一段。仅播放当前详细预览的动图；视频和矢量贴纸的动图预览取决于转换依赖，过大的动图用静态预览。

QQ 扫描结果的「导入到」旁可以新建并选中图库分类，不改动 QQ 缓存。QQ、TG 入库时若目标分类没有图标，会取第一张成功入库的表情作为图标，保留已设置的图标。TG 的「批量打包」每行接收一个包名或链接，按输入顺序入库，每包生成一个可重新导入的 ZIP v1（含 `TG.txt` 来源链接）。页面显示每包的进度和详情，单包失败不影响后续包；取消保留已完成的 ZIP 和已写入图库的图片。重名时不覆盖原 ZIP，也不混入已有分类。

解析 TG 单包后可点「导出为资源包」。默认用包标题作为资源包 ID，可改名。ID 同时是收藏夹名和 `<ID>.zip` 基础文件名；同名收藏夹已有的表情也会一起打包。它处理已解析的全部贴纸，与当前勾选及普通下载的格式选项无关。获取失败的贴纸跳过并列出；清洗入库或打包失败不会发布 ZIP，已经入库的表情保留，可用同一个 ID 重试。只有用户确认覆盖，且新包成功生成后，才会替换旧 ZIP。

只要文件时，在 QQ 扫描结果中选「导出所选」或「导出全部」，再选图库和 QQ 缓存以外的文件夹。按实际图片格式补上可用的扩展名，商店表情恢复为 GIF，APNG 转成多帧 GIF（转码失败时尝试保留原 PNG）；其他格式复制原内容。重名自动加后缀，不覆盖已有文件。支持看进度和取消，取消保留已导出的文件，不改动图库或 QQ 源文件。

主面板默认 `Ctrl+Shift+E`（`global_hotkey`）；快速面板默认 `Alt+2`（`quick_panel_hotkey`），在光标旁打开，失焦或按 Esc 收起。快速面板空搜索显示最近使用，搜索只匹配关键词，最多显示 30 个匹配。最近使用沿用旧版 SQLite/JSON，两个面板共用。

快速面板内 Ctrl＋滚轮可独立调节缩略图大小，沿用旧版 `quick_panel_thumbnail_size` 并自动保存。缩放不清空搜索，不影响主面板的尺寸设置。

在设置页点击快捷键输入框，直接按组合键录入。快捷键留空不注册。支持 Ctrl/Alt/Win 组合及 Shift + 功能键，不注册裸按键或只用 Shift 的输入按键；如果快捷键被占用，设置中会标出对应输入框，仍可通过托盘打开并修改。切换预览版前请先从托盘退出旧实例，否则旧实例可能仍占用快捷键。托盘可用时关闭主窗口会收起，托盘菜单里可退出。可用 `--autostart` 请求从托盘启动，这个参数不会注册开机启动。

主窗口会记住普通状态下最后的位置和大小；最大化、最小化不会覆盖它。启动、重新唤起和显示器变化时都会检查：原显示器断开或窗口完全离开所有显示器的工作区，就在主屏工作区内居中。只拔掉无关的显示器或窗口仍部分可见时不改变正常位置。从托盘启动时不会因归位而自动弹出。WPF 将位置保存到图库下的 `window-placement.windows.json`，不改旧版 Qt 的位置记录；快速面板仍在光标旁唤出。

在支持粘贴图片的输入框里按快捷键，再点选表情。两个面板共用发送路径：剪贴板同时提供文件路径和可解码时的位图兜底。开启 `convert_static_to_gif` 时，静态图按旧设置转换为单帧 GIF；GIF、APNG、动态 WebP 保留原文件。面板显示前记录原来的前台窗口和可识别的原生输入控件。选图后短暂等待原窗口恢复焦点，最多自动粘贴一次；若窗口身份、输入控件或剪贴板变化，或者修饰键未及时释放，则不发送按键。普通打开和从托盘打开只复制。

开机启动的系统注册、内置更新和正式发布包尚未迁移。位图兜底取决于本机编解码器；APNG 手动或自动导入会转为可预览的 GIF，但直接存在图库内的原格式 APNG／动态 WebP 尚无完整的动画预览。

需要在源码目录外试用时，用 [Windows 2.0 本地封包工具](windows-packaging.md) 生成携带 Python 和精简 FFmpeg 的 ZIP；它不是 1.x 更新包，也不上传发布。

## 交互迁移验收

以现有 Qt 前端为交互基准。除用户明确要求的改动（例如主图库固定从左上角排列）外，更换技术栈不改变操作方式。每条路径按旧版核对入口和快捷键、成功／重复／失败反馈、是否阻断操作，以及焦点、滚动和返回行为。入口能用不等于交互已经迁完。

未迁入口及同功能仍存在的交互差异，见 [旧版功能迁移核对](windows-migration-audit.md)。例如主面板普通打开后，WPF 不会向此前记录的窗口自动粘贴。

## 结构

- `Controls/FluentMenu.xaml` 与 `FluentMenu.cs` 提供动作、勾选项、分隔线和子菜单。主菜单和子菜单共用浅深色、行高、圆角和阴影，图标和勾选列按菜单层独立对齐。展开、键盘导航、屏幕边缘重新定位和关闭沿用 WPF 菜单机制。
- `CategoryIcon` 为侧栏、菜单、下拉框和分类选择窗口统一解析图片、Emoji 和默认图标。菜单图标和勾选标记分列对齐；普通菜单不占额外图标列。
- 托盘右键菜单同样使用 `FluentMenu`，保留旧版「显示主面板／设置／退出」。托盘、分类、表情、筛选和下拉菜单共用 `FluentMenuPalette`，切换浅深模式或所选配色时统一更新。托盘图标和气泡仍由 Windows 通知区域承载。
- `FluentScroll.xaml` 为分类侧栏、图库、页面和菜单提供同一套纵向滚动条。内容溢出才显示，滑块悬停或拖动时提高对比度。
- 分类图标网格和主图库共用 `TileColumns` 与 `WheelZoom`；网格内滚动条悬浮在留白上，不会挤掉恰好放得下的一列。主图库仍按可见范围虚拟化。
- 新页面通过 `PageRoute` 注册到 `FluentPageHost`，图库入口用 `MainWindow.OpenPage`，子页用宿主的 `Push`。宿主拥有页头、返回／Esc、焦点和退出检查；父页挂起时保留同一实例。页面只声明自己的暂停、恢复、释放钩子和页内返回（例如先关闭相似度大图）。设置、感知哈希、导入导出及 QQ／TG 子页都走这套导航。
- 页面任务通过 `OperationScope` 声明离页策略：只读扫描用 `CancelOnLeave`，不可中断的写入用 `FinishBeforeLeaving`，可安全收尾的 QQ 导出和 TG 批量写入用 `CancelAndWait`。宿主管理返回时的取消／阻拦和整栈退出预检；任务租约过滤取消或结束后的迟到进度，`OperationProgress` 负责显示和发出取消请求。
- `PreferenceState` 分开维护本地预览、待写设置和已保存快照。较早的保存回复不覆盖更新的滚轮预览，失败时恢复已保存值。快捷面板尺寸和主题原地更新，不因设置保存丢掉搜索；自身的缩略图尺寸读取有效值，其他设置仍读取已保存的快照。
- 新建分类、重命名、分类选择和确认窗口共用 `FluentDialog`，与页面共享 `FluentFields`；导入导出动作卡片与设置页共用 `SettingCard`。两者不依赖 Qt 界面，分类写入仍走 `LibraryCommands`。
- QQ 和 TG 共用 `VirtualMasonry` 瀑布流、详细预览和选择，通过 `services/external_stickers.py` 调用旧扫描器／下载器。卡片按视口创建和回收；缩略图、详细预览和导入各走独立通道。WPF 的 TG 单包和批量打包共用原文件下载、清洗入库和 ZIP 组装，只区分分类命名与文件发布规则。Qt 批量也共用 `services/tg_batch_export.py`，两套前端的资源包由 `services/tg_package_zip.py` 统一装配。
- `StickerPreview` 统一主面板和快速面板的圆角悬停预览，使用随浅深主题变化的淡细描边。只要主面板仍在鼠标下可见，即使它不在前台也能悬停预览，不夺取焦点；快捷窗口的失焦收起行为不变。`InlineNotice` 提供不抢焦点、自动消失的图库内提示。
- `Desktop/DesktopSession.cs` 组装托盘、快捷键和点击复制。全局快捷键由单独的不可见消息窗口接收，不依赖主面板是否显示。`PanelWake` 保管当次快捷唤出的目标，`AutoPaste` 验证目标后才交给 Win32 输入层。
- 两个面板共用 `FluentTheme`、`VirtualGallery` 和 `PreviewPopup`，布局参数由各自视图决定。`QuickPanelResults` 管理快速搜索与会话最近使用。`services/send_media.py` 是 Qt 与 WPF 共用的静态转换服务，不依赖 UI 框架。
- `LibraryCommands` 串行化同一 WPF 实例的工作，使用 UTF-8 JSON 调用 `services/gallery_commands.py`。图库读写、导入、资源包和相似度沿用无 Qt 的服务；去重进度以独立消息回传，取消只结束扫描子进程，已经提交的 `similarity-v1.db` 特征缓存可复用。删除不在写入中途取消。
- `ClipboardImageSource` 解析剪贴板和拖拽数据；`services/network_image.py` 下载至临时文件，限制协议与响应大小。`ImportQueue` 串行分发手动导入，让同一进度组件显示取消和等待数。`OperationScope` 与 Python 端的取消标记协作，让工作在安全边界结束。`InboxMonitor` 在后台观察收件箱，`services/inbox_import.py` 复查并暂存确认的文件。普通文件、链接和收件箱入口都交给同一个 `ImportJob` 清洗、转码、查重。
