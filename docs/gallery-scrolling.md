# 图库滚动与缩略图调度

滚动优先于加载。图库按完整路径列表确定总高度，只为当前屏幕及前后各一屏创建卡片。缩略图完成加载不会改变行高、列宽或滚动范围。

`VirtualGallery` 在滚动停止 140ms 后恢复工作。滚轮动画、触控板惯性、拖动滚动条和中键滚动模式期间，不创建卡片、不提交新解码任务；已完成的结果暂存到卡片，停稳后再显示。每 16ms 最多处理四张卡片，单批仍预算 2ms，单项工作仍可能超过预算。卡片创建和图片解码同时推进，当前屏幕的图片不再等待预加载区域的占位卡片全部建好。缩略图调度间隔为 8ms，单批最多四张、预算 2ms，已加载的卡片跳过调度。解码池使用两个线程，每个面板仍最多保留两个待完成请求，避免慢图片堵住其它图片或形成长队列。快速滑到未准备区域时允许暂时空白。

主面板和快捷面板都支持两种中键操作：按住中键拖动内容，松开停止；原地单击中键进入自动滚动，鼠标在点击位置上方或下方决定方向，距离决定速度，中心保留 10px 静止区域。再次点击、按 Esc、滚动滚轮、隐藏面板或切换窗口会结束自动滚动。结束模式的点击不会触发图片选择或粘贴。中键模式保持加载及悬停预览暂停，即使鼠标暂时位于静止区域，也不会在操作中途恢复加载。

重新呼出时，路径列表未变就保留卡片、图片和位置。空闲缩减 QPixmapCache 不会清除可视卡片持有的图片。隐藏会暂停调度，再次显示会恢复。多选区间、拖动插入位置、排序依据完整数据计算，不依赖控件是否已经创建。

## 回归验证

```powershell
$env:QT_QPA_PLATFORM='offscreen'
$env:PYTHONPATH='tests'
python -B -m unittest test_middle_scroll test_gallery_scrolling test_window_resize test_hover_preview -q
```

覆盖连续滚动无新卡片和解码提交、万张图库跳转不累积控件、滚动范围固定、缩放、空闲缓存清理后呼出、加载中隐藏再显示、过期结果丢弃、跨未加载区域的多选和排序，以及快捷面板延后加载。

另覆盖两种中键模式、双击退出、取消点击不误粘贴、Esc/隐藏/切换窗口清理、当前屏幕优先解码、等待中的解码恢复，以及一张慢图不阻塞另一张快图。

本地离屏探测（2026-10-18，800×600、80px 卡片、10,000 项）：初始只创建 104 张卡片；240 次像素滚动期间新建卡片和解码提交均为 0，滚动范围不变。事件发送及当前队列处理耗时 P95 为 3.551ms，最大 6.077ms。使用 12 张 500×400 PNG 循环排列，该结果不代表真实桌面呈现帧率；打包后仍需用实际图库、鼠标和触控板验证。

后续加载调度对照（同日离屏，800×600、80px 卡片、10,000 项，24 张 600×480 PNG 循环，清空缩略图缓存）：以原有的“占位全部完成后才解码、单解码线程、每批两张”调度参数作对照，首图约 1631ms、首屏约 2149ms；新调度首图约 45ms、首屏约 687ms。240 次连续像素滚动均没有新建卡片或新解码提交，事件处理 P95 约 6.55ms → 6.24ms，最大值约 15.45ms → 17.65ms。单次测量受系统调度影响，不能据此保证所有图库的加载时间或真实帧率。
