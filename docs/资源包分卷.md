# 资源包切割分卷

在「导入导出」页面点击「资源包切割分卷」，选择已经导出的 ZIP 资源包，再选择保存文件夹。

程序会创建一个新的子文件夹，生成 `原包名.part001.zip`、`原包名.part002.zip` 等文件。原资源包不会被修改或覆盖。每卷最多 100,000,000 字节，包含图片、分类图标、清单和 ZIP 本身的开销。小资源包只生成一卷。

图片按完整文件分配，不缩放、不转码、不改变图片字节；动图也保持原始内容。分卷采用 ZIP 存储方式，因此分卷总大小可能比原压缩包更大。写入后会检查实际大小并核对图片的 SHA-256。

下载后，使用现有「导入资源包」功能逐卷导入即可。各卷可以独立导入，顺序不限；原有分类名称、图标和关键词保留，同名分类会合并，重复图片按现有规则去重。导入全部分卷后才包含完整资源包的所有图片。

默认单张图片小于 100 MB。如果某张图片连同必要清单和图标仍超过上限，程序会报错，不会损坏图片或生成超限分卷。损坏的资源包也会停止处理。
