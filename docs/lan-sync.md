# 局域网双向同步

Windows 和 Android 都更新后，在两端的「导入导出 → 局域网同步」中配对。手机可扫电脑上的二维码，也可输入六位配对码；自动发现不可用时，可同时填入电脑显示的地址。核对校验码并在两端确认连接后，任意一端点「同步两端」，另一端允许即可。

- 首次连接合并已有图库，相同内容去重，同名收藏夹合并，不按另一端的空图库删除本地内容。
- 下次同步会比较上次共同图库。单端新增、删除、改关键词、加进或移出收藏夹、收藏夹改名或换图标，以及收藏夹和「全部表情」的排序，会传到对端。Android 的单个收藏夹内部排序仍是本地设置。
- 各自修改不同关键词或成员关系可以合并；两端给同一个收藏夹改成不同名称、设置不同图标、同时作了不兼容的排序，或一端删除而另一端编辑同一项时，本轮不会写入。调整其中一端后可重新同步。
- 图片复用原来的 ZIP v1，只有对端缺少的静态 PNG、GIF 和收藏夹图标才打包。Windows 上不在 ZIP v1 资源范围内的图片保留在本机；如果待删除的收藏夹含有这些图片，同步会停止，避免丢失其归类。
- 同步删除的原文件移动到各自数据目录下的 `lan-sync-trash`（Android 位于应用私有目录）。断线后重新配对并同步，会继续从两端最后共同应用的版本对账。设备端同步记录随图库保存，不要单独清除。

原有「发送」「接收」仍是单次资源包导入，不传播删除；旧版只支持这些操作。
